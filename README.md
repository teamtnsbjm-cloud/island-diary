# 🏝️ 무인도 일기 (공개 서버판)

누구나 링크만 누르면 로그인 없이 들어와서 같은 섬에서 만나는 3D 웹 게임이에요.
섬(채널)은 20개이고, 섬 하나에 최대 100명까지 들어올 수 있어요. 화면 왼쪽 위에 "섬 3 · 12/100명"처럼 실시간 인원이 떠요.

```
island-server/
├─ server.js        ← 게임 페이지와 실시간 접속을 같이 처리하는 서버
├─ public/index.html← 게임 화면 전부 (3D 섬, 낚시, 물물교환, 채팅)
├─ package.json     ← 서버 실행 정보
└─ render.yaml      ← Render 배포 설정 (무료)
```

---

## 1. 내 컴퓨터에서 먼저 해 보기

1. Node.js를 설치해요: https://nodejs.org 에서 **LTS** 버전을 받아 설치
2. 이 폴더에서 터미널을 열고:

```bash
npm install
```

```bash
npm start
```

3. 브라우저에서 http://localhost:3000 을 열어요.
4. **창을 두 개 열면** 두 캐릭터가 같은 섬에서 서로 보여요. 이렇게 멀티플레이를 확인하면 돼요.

---

## 2. 인터넷에 올리기 (Render, 무료로 시작)

1. https://github.com 에 가입하고, 새 저장소를 만들어 이 폴더의 파일을 올려요. (`node_modules` 폴더는 올리지 않아요)
2. https://render.com 에 GitHub 계정으로 가입해요.
3. **New → Blueprint**를 누르고 방금 만든 저장소를 고르면, `render.yaml`을 읽어서 자동으로 설정돼요.
4. 몇 분 뒤 `https://island-diary-xxxx.onrender.com` 같은 주소가 나와요. 이게 게임 링크예요. 인스타 프로필 링크에 넣으면 돼요.

### 알아 둘 점
- **무료 플랜은 15분 동안 아무도 없으면 서버가 잠들어요.** 다음 사람이 들어올 때 깨어나는 데 30초~1분 정도 걸려요. 계속 켜 두려면 유료 플랜(월 7달러쯤)으로 바꾸면 돼요.
- 사람이 정말 많아지면(동시 수백 명 이상) 더 큰 서버가 필요해요. 그때 말해 주세요.
- 진행 기록(물고기, 모자, 꾸미기)은 각자 브라우저에 저장돼요. 다른 기기에서 들어가면 처음부터 시작해요.

---

## 3. 내 도메인 붙이기 (선택)

`metamong-island.com` 같은 주소를 쓰고 싶으면:
1. 가비아, Cloudflare, Namecheap 같은 곳에서 도메인을 사요 (1년에 1~2만 원쯤).
2. Render 서비스 화면의 **Settings → Custom Domains**에 도메인을 추가하고, 안내대로 도메인 회사에 DNS를 입력해요.

---

## 4. 바꿀 수 있는 설정

Render의 **Environment**에서 바꿀 수 있어요.

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `ISLAND_CAP` | 100 | 섬 하나당 최대 인원 |
| `MAX_ISLANDS` | 20 | 섬(채널) 개수 |

## 5. 친구 초대

게임 안에서 왼쪽 위 **섬 번호**를 누르고 **초대 링크 복사**를 누르면 `?island=3` 같은 링크가 복사돼요. 이 링크로 들어온 친구는 바로 그 섬으로 와요.

## 접속 상태 확인

- `/health`: 서버가 살아 있으면 `ok`
- `/api/islands`: 섬별 현재 인원 (JSON)

## 메타모아 연결 (접속자 수)

- **접속자 수 주소**: `https://island-diary.onrender.com/api/live` → 지금 섬에 함께 있는 사람 수를 숫자 하나로 돌려줘요.
  브라우저로 들어와 섬에 입장한 사람만 세고, 스크립트·봇 접속은 빼요. 이용자 정보는 들어 있지 않아요.
  메타모아 등록 신청의 「접속자 수 API」(live_api) 칸에 이 주소를 넣으면 돼요.
- **10분마다 보내기**: Render → Environment에 아래 두 값을 넣으면 서버가 10분마다 숫자만 보내요. 값이 없으면 보내지 않아요.
  - `METAMOA_KEY`: https://metamoa.com/owner 에서 소유자 확인 후 받은 공간 키
  - `METAMOA_SPACE_ID`: 메타모아 공간 id
- **알림(웹훅) 받는 곳**: `https://island-diary.onrender.com/api/metamoa-hook` (POST, 내용은 서버 로그에 남아요).
  `METAMOA_HOOK_TOKEN`을 정해 두면 `?token=그값`이 붙은 요청만 받아요.
